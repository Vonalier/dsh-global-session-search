# 全局会话搜索

跨所有工作区搜索 DSH 的全部历史会话与记录。

## 用法

安装并启用后，在对话中调用 `global_session_search`：

- `query`：要搜索的字面文本，大小写不敏感，中文与标点原样匹配。
- `limit`：最多返回多少条匹配记录，默认 30，最大 100。
- `session_id`：只搜索某一个会话；不填则扫描全部会话。

返回结果包含会话 id、标题、工作目录、命中记录的类型/序号/时间与上下文片段。页面支持按最新/最早排序，并按记录类型、时间范围、会话筛选。先用 `session_id` 定位会话，再查看该会话的更多记录。

## 说明

- 扫描 DSH profile 的 sessions 目录，不按当前工作区过滤。
- 搜索范围包括用户消息、助手消息、系统消息、工具调用与工具结果等记录。
- 不会修改任何会话，也不会向会话写入内容。
